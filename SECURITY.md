# Security

Bazaar handles on-chain GNOT. Do not open public issues that include exploit payloads, private keys, or mnemonics.

Report suspected realm bugs privately to the maintainers. Money paths fail-closed (`panic` reverts the tx).

Production is **gno.land mainnet**. GNOT has market value. Factory bazaarv2: Reserve-only launch fee; `Withdraw` leaves reserved ugnot.
