## BUG-BUY-1 — Empty book vẫn hiện sample **For sale** + Buy

**Severity:** P2 (live book vs catalog)  
**Where:** `web/src/components/Explore.tsx` `forSale`

```ts
if (items.length > 0) return items.filter((row) => row.listed && row.price > 0);
return catalog.flatMap((col) => previewItemsFor(col).filter((row) => row.listed && row.price > 0));
```

`items.length === 0` gồm: loading, realm-missing, **và** `ListOpen()` rỗng thật. Chỉ realm-missing có `chainNote` + `isRealmUnavailable`. Empty book không có note → For sale = catalog (`Ember Core` 1 GNOT, …) với nút Buy.

**Repro**

1. Local gnodev, Init NFT, **không** `SeedSamples`. (Pearl addpkg xong, book rỗng cũng vậy.)
2. `cd web; npm run dev` → http://127.0.0.1:5176 — network **Local**.
3. Explore, không search.

**Expected:** empty `No open listings` (hoặc For sale trống).  
**Actual:** section For sale + Buy trên sample. Click Buy khi đã Connect → `onConnect()` lại, không `Buy` tx (`isPreviewItem` = `!id`).

Pearl undeployed **có** chain-note — không nhầm empty book, nhưng CTA Buy trên sample vẫn giống listing live.

**Expected:** card disable như drawer; own listing → Cancel hoặc ẩn Buy.  
**Actual:** CTA Buy.
